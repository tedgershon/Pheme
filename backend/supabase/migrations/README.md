# Archived SQL history

These files are reference material and legacy test fixtures, **not a migration
chain**. Do not sort or replay them against a database. Duplicate numeric
prefixes refer to different changes; the consolidated snapshot also omits
later fixes and includes an obsolete account-specific privilege assignment.

The executable chain is [supabase/migrations](../../../supabase/migrations/).
Use [the migration guide](../../../docs/MIGRATIONS.md) for fresh bootstrap,
checked legacy adoption, forward upgrades and operator privilege bootstrap.
